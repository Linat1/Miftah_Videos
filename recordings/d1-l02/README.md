# Voice recordings for D1-L02 · "Yusuf's Busy Wednesday"

Put your recordings here, **one file per line**, named after the line id:

`s1-01.m4a`, `s1-02.m4a`, … `tip-1.m4a`, `q-1.m4a`, `end-1.m4a`

The full list of lines (with Arabic, English and approximate length) is in
`docs/D1-L02-story-script.md`.

Then run:

    npm run voices:d1-l02

It trims the silence, evens out the volume, and re-times the video to your voice.
