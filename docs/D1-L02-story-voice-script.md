# D1-L02 story · "Yusuf's Busy Wednesday": voice recording script

Running time with estimated timings: **2:44** (it adjusts to your recordings).

## How to record

1. Record **one file per line**, e.g. with your phone's voice recorder. Leave a second of silence before and after; it's trimmed automatically.
2. Name each file after its **File** column below (e.g. `s1-01.m4a`). Any of m4a, mp3, wav, ogg works.
3. Put the files in the folder `recordings/d1-l02/`.
4. Run `npm run voices:d1-l02`. The video re-times itself to your recordings.
5. Preview with `npm run dev` (choose **D1-L02-Story**), then render with `npm run render:d1-l02-story`.

You don't need to record everything at once: lines without a recording keep the music and captions.
Tip: give each character a slightly different voice. Students can play the parts!
