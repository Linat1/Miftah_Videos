# D1-L02 · Telling the Time — voice-over script

Total length: **3:22.8**. Each line shows the moment it should start.

**How to record:** record one continuous take while watching the video in `npm run dev` (muted),
reading each line when its time appears. Save it as `public/audio/d1-l02-narration.mp3`, then in the
Studio set **narrationFile** to `audio/d1-l02-narration.mp3`. For exactly matching captions, run
`npm run captions -- public/audio/d1-l02-narration.mp3` and set **captionsFile** to the JSON it makes.

Narrator lines are in English. Character lines are in Arabic, so you can voice them yourself or with
students playing the roles.
